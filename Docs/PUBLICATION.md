# Public early-beta publication · 2026-11-04

At the owner's explicit request, the GitHub repository and existing v0.1.0-beta.1
prerelease are made publicly accessible. This is early test access, not completion
of all platform acceptance or a legal clearance statement.

The beta was initially prepared for private closed testing. Historical attachment
names, original archive contents and validation records retain that context. Their
original hashes and the release tag are preserved. The current Release notes and
repository README describe the public-access change.

Self-authored code remains GPL-3.0-or-later. Original upstream license/copyright
notices, exact Android core sources, local patches, rebuild scripts and SHA-256
remain available. Personal learning and non-commercial intent add no restriction
to GPL recipients and do not grant third-party artwork rights.

The current APK and appearance input pack retain the owner's requested themes.
Third-party artwork, console marks and game covers are not relicensed by this
project; their public redistribution rights have not been established by the
source audit. Public visibility does not turn that audit item into a passed one.

The source snapshot and uploaded packages were checked for game/save file paths,
recognized game payload signatures and project signing credentials. ROMs, personal
saves and signing keys are not supplied. Users import their own authorized game
files. The project does not provide commercial ROM download links.

Only Android ARM64 has an installer in this beta. Its isolated package ID prevents
replacement of the existing developer app. Physical beta-package revalidation,
complete Android/iOS parity and some PSP performance cases remain pending.
Apple installers still require exact core provenance and distribution signing.

See UPSTREAM.md, THIRD_PARTY_NOTICES.md and the Release installation/known-issues
notes for source attribution and the actual tested scope.

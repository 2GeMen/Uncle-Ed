经典再次上场。此版本保留现有外观，发布在私有 GitHub 仓库。它是个人 VibeCoding 学习项目，非商业化用途；这项定位不增加或减少开源许可授予的权利，也不代表取得第三方素材的再分发授权。不要将本测试包视作已获准公开发行的版本。

## 本次提供

- Android 9 及以上、ARM64 设备的独立签名测试 APK，包名 org.uncleed.app.beta。
- SHA-256 校验清单、安装与导入说明、已知问题、开源许可。
- 前端源码；三个 Android 核心的对应源码快照、固定依赖、本地补丁、重建脚本及二进制溯源。

不包含 ROM、商业游戏光盘镜像、个人游戏库或存档。App 提供用户文件导入、资源匹配与游戏管理。联网匹配可能查询游戏名称、机型和地区，不上传 ROM 或存档；离线时资料可能不完整。

## 安装与更新

1. 从本仓库 Release 下载 Uncle-Ed-0.1.0-beta.1-android-arm64.apk。
2. 核对 SHA256SUMS.txt：macOS / Linux 可运行 shasum -a 256 文件名；Windows 可用 Get-FileHash 文件名 -Algorithm SHA256。
3. Android 按系统提示允许当前文件管理器安装该 APK，安装后可关闭此授权。
4. 测试版与原开发版并存，独立保存游戏库和存档，不会自动搬移旧版数据。不要为了安装测试版卸载原版。
5. 打开 App，用右上角导入按钮选择自己有权使用的游戏文件；从选择掌机、主题、卡带进入游玩。无需导入任何密钥或固件来使用 GBA/GBC。
6. 后续相同包名、相同签名的更新可覆盖安装。卸载会删除该测试版的本地数据，先备份重要进度。

## 随时保存

游戏菜单中的“存下此刻”保存手动断点，“恢复手动存档”会回到该时刻；“继续上次离开”读取正常退出时生成的自动断点。每个游戏目前各一份。依赖核心支持和兼容版本；强制杀进程或断电不保证保存最新进度。即时状态不是游戏内存档，也不是云同步，不保证在不同平台/不同核心版本之间通用。

## 已知问题与验证边界

- 这是测试版。Android 与 Apple 端的完整视觉、交互一致性尚未全部验收。
- OPPO Find X6 的历史开发版验证不等于本独立签名包已完成新一轮真机验收；本包另做本地模拟器安装启动检查。
- Android 平板尚无真机验收；3DS Android 游玩未启用。编译通过不代表所有设备和游戏兼容。
- PSP 部分大型游戏仍可能卡顿或出现音频断续，尤其是加载、开场和重负载场景；不宣称已解决。
- 首次模型加载可能较慢，软件 GPU 模拟器尤其明显。
- 自动封面及资料匹配可能缺失或匹配错误，网络服务可用性会影响结果。
- 新即时存档已做有限核心场景检查，不等于所有游戏的长期可靠性已验证。

## Apple 安装包状态

本次不附通用 Mac / iPhone / iPad 安装包。现有 Apple 核心来自夜间二进制，尚未建立所有核心的精确对应源码链；当前可用证书也只有 Apple Development。不能把它们包装成已签名公证的通用 Mac 发行包，或所有用户可安装的 IPA。

下一步需完成 Apple 核心来源/对应源码核验，并配置 Developer ID 签名公证（Mac）以及合适的 TestFlight / App Store 分发身份（iPhone / iPad）。此项未完成，不代表全平台发布已交付。

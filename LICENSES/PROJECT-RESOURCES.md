# Project resources and owner publication instructions

On 2026-11-17 the project owner explicitly requested inclusion of the existing
Uncle Ed application icon and all runtime presentation resources in the public
source and downloadable applications, matching the original local build.

The existing project branding and synthesized mechanical audio are included for
building and distributing Uncle Ed applications. This notice records the owner's
inclusion instruction; it does not assert ownership of third-party designs or
create a blanket license for third-party character prints, console marks or game
cover illustrations. Those rights remain with their respective holders.

Shared/asset-provenance.json distinguishes approved project resources from
owner-authorized third-party presentation resources whose redistribution rights
have not been independently verified. The latter must not be described as GPL
artwork or as having passed a third-party rights review. Code remains under its
existing licenses. Upstream replacement system resources retain their source
notices in Assets/Licenses and the emulator corresponding-source packages.

No ROMs, personal saved games or signing credentials are included. Model/runtime
resources are supplied at full existing quality; no substitute icons or generic
themes were introduced for the public source build.
